# Districted Demo

A lightweight prototype for a Washington DC location-guessing game.

## Gameplay

- Five DC locations per daily game
- One map pin guess per location
- Instant answer reveal
- Distance-based color scoring
- Final score is total miles off

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL in your browser.

## Notes

This demo uses OpenStreetMap raster tiles directly. For production, consider Mapbox, MapLibre, Leaflet, or Google Maps with proper usage limits and attribution.
